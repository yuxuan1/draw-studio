# StateFlow Studio

**状态机 / 流程图 / 白板 三合一可视化设计器** —— 纯前端、离线可用、零后端依赖。

以 Stateflow 风格的转移标签 `event[condition]{condition_action}/transition_action` 为核心，
面向嵌入式 / 航空电子 / 状态建模场景，同时覆盖流程图（含可递归展开的子流程）与白板标注。

## ✨ 功能特性

### 状态机
- 四类形状：普通状态 / 终止状态（双线框）/ 连接点 / 初始结点
- Stateflow 标签四段编辑：`event[cond]{cond_action}/action`，画布实时渲染胶囊标签
- 属性面板完整编辑 entry / during / exit 动作、备注、8 色板配色
- 同类型元素自由连线生成状态转移，跨类型连线被禁止并提示

### 流程图
- 开始 / 流程 / 判定 / 输入输出 / 子流程 五种形状，填充、边线、尺寸全可调
- 主流程**默认纵向（TB）排列**，可在外观面板切换横向/纵向并重新排布
- **子流程**：`[[计算过程B]]` 可递归展开为独立小流程图，再嵌套 `[[计算过程E]]`…
  - 展开时在侧向弹出**浮动面板**（自动避让周围元素；纵向流程优先右/左侧，横向流程优先下/上侧），虚线系绳连回结点
  - 面板位置与内部结点布局**全部被记忆**，收纳后再次展开回到原处
  - 首次展开自动布局，之后保留手动摆位，可一键「整理内部」
- 流程图层级自动布局（LR / TB），同层连线、自环支持

### 白板（独立页面类型）
- 插入本地图片作底图，图片之上叠加矩形 / 椭圆 / 箭头 / 直线 / 文字标注
- 拖拽绘制、图层置顶置底、所见即所得导出

### 通用能力
- **多页面**：顶栏页签切换，右下角 ＋ 按钮选择新建「画布页」或「白板页」
- 撤销 / 重做（100 步）、500ms 防抖自动保存到 localStorage、刷新自动恢复
- 明暗双主题、点阵网格、小地图、适应视图（`F`）、缩放 0.15×–2.5×
- 导出自包含 SVG / PNG（1×–4×），一键复制到剪贴板
- 全中文界面，帮助菜单含快捷键速查与标签语法说明

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 开发模式（热更新）
npm run dev          # 打开 http://localhost:5173

# 构建生产版本
npm run build        # 产物在 dist/
npx vite preview     # 本地预览产物
```

## ⌨️ 快捷键

| 操作 | 快捷键 |
|---|---|
| 撤销 / 重做 | `Ctrl/⌘+Z` / `Ctrl/⌘+Shift+Z` |
| 适应视图 | `F` |
| 选择工具 | `V` |
| 删除选中 | `Delete` |
| 展开 / 收纳子流程 | 双击结点 或 右上角 `+N` 徽标 |
| 取消选择 | `Esc` |

## 🏗 项目结构

```
src/
├── App.tsx                  应用外壳
├── studioStore.tsx          全局状态：文档/历史/页面/选择/工具/Toast
├── lib/
│   ├── core.ts              数据模型、标签引擎、文本度量、8 色板
│   ├── geometry.ts          连线几何（锚点/平行边/自环/箭头，画布与导出共用）
│   ├── layout.ts            状态机自动布局（LR/TB/环形/网格）
│   ├── studio.ts            多页面模型、子流程面板、碰撞避让选址
│   └── boardkit.tsx         共享工具：历史栈 Hook、图标、导出
└── components/
    ├── UnifiedCanvas.tsx    统一画布（三类元素共存、拖拽/连线/缩放）
    ├── UnifiedPanels.tsx    左侧插入面板 + 右侧属性面板
    └── UnifiedChrome.tsx    顶栏/页签/底栏/导出弹窗/帮助
```

## 🌿 分支模型

- `dev`：日常开发分支，所有新功能先落到这里
- `main`：稳定主分支，只接受来自 `dev` 的合并（Pull Request）
- 每次推送 / PR 会自动触发 CI 构建验证（`.github/workflows/ci.yml`），通过后才可合并

```
dev  ──●──●──●──●──┐
                   ╰─ PR ─▶ main ──●── (发布)
```
